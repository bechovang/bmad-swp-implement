### 2 — decision — 2026-09-11
Phạm vi nghiệp vụ (từ 7 flows):
- F1 Đặt kho: KH tìm kho (loại/kích thước/ngày/thời hạn) → hệ thống check lịch thuê + Turnover Buffer → chọn kho → tính tổng tiền, cọc 10% → thanh toán qua gateway → kho = Đã đặt.
- F2 Check-in & bàn giao: KH đến, đưa mã đặt chỗ → NV kiểm tra → hệ thống validate (đặt chỗ hợp lệ + đã cọc) → KH trả 100% phí thuê → bàn giao khóa/thẻ/mã truy cập → kích hoạt phiên thuê, kho = Đang được thuê.
- F3 Checkout/trả kho: KH dỡ hàng → NV nhận lại kho + khóa/thẻ, kiểm tra tình trạng → phụ phí? → khấu trừ cọc / hoàn cọc / KH trả thêm → đóng phiên thuê → kho = Đang chuẩn bị → dọn dẹp → bảo trì? → có đặt chỗ tiếp? → Đã đặt / Có thể cho thuê.
- F4 Chính sách – phí – doanh thu (Quản lý vận hành kinh doanh): cấu hình giá thuê + phụ phí theo loại kho, validate & lưu chính sách; theo dõi kinh doanh theo kỳ: xem doanh thu/tiền cọc/phụ phí/mức sử dụng, xuất báo cáo.
- F5 Cơ sở vật chất – nhân viên – vận hành (Quản lý cơ sở kho): CRUD Storage Unit / gom kho / ngừng dùng / bảo trì (check Rental + Reservation + lịch sử); phân công NV (nhân viên / khu vực / ca, check xung đột); theo dõi công việc phát sinh (Check-in/Checkout/Dọn dẹp/Support) → NV thực hiện, cập nhật kết quả; sửa trạng thái kho sai + lý do → Activity Log.
- F6 Gia hạn theo ngày: KH chọn thời gian gia hạn → check xung đột Reservation tiếp theo → tính phí gia hạn → thanh toán → cập nhật checkout mới.
- F7 Hỗ trợ & sự cố: KH chọn kho + loại sự cố + mô tả → Support Request → route NV phụ trách (kho + ca) → NV xử lý hoặc escalate Manager → nghiêm trọng? → đưa kho vào bảo trì + chuẩn bị kho khác cho KH → cập nhật Đã xử lý, KH xem kết quả.

Trạng thái kho xuất hiện: Có thể cho thuê / Đã đặt / Đang được thuê / Đang chuẩn bị (+ Bảo trì / Ngừng dùng từ F5).
