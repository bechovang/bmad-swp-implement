StorageHub — Design Directions 01–04

Same hero screen (Browse Units, customer role, adaptive shell) rendered in four complete visual personalities: density, type weight, corner language, elevation and brand register all change — not just color. Each direction is paired with a small secondary screen (Unit Detail S-3 or the Browse empty state) and shows at least one component state variant (turn-over buffer card, scarcity card, or empty state). Currency is VND, formatted 1.150.000 ₫. Light mode only.

Direction 01

Manifest — Utilitarian Industrial

An operations-first register borrowed from warehouse signage and shipping manifests. Squared corners, hard 1.5px borders, a safety-orange accent and dense 13px type put throughput and legibility above charm — the whole screen reads like a packing slip a depot manager already trusts. Elevation is expressed as weight of line, never shadow.

Direction 01 — at a glance

  • Register: utilitarian-industrial / depot software. Trust through density and precision, not delight.
  • Corner language: 2px radius everywhere; square badges and avatar; borders over shadows (2px ink on primary panels).
  • Type: mono for every number, code and code-like token (S-1, prices, dates); 9.5–10px uppercase letterspaced labels.
  • States shown: turn-over buffer card L-3 (tape strip + amber availability); Unit Detail spec-sheet secondary.
  • Signature: ink status ticker above the nav; safety-orange reserved strictly for action + alert.
Direction 02

Storefront — Friendly Consumer

A warm, consumer-marketplace register that makes renting a lockable unit feel like booking a homestay. Generous 16–18px radii, soft layered shadows, a coral primary and sage secondary lower the stakes for first-time self-storage users. Type is larger and rounder in feel, with friendly microcopy throughout.

Direction 02 — at a glance

  • Register: friendly consumer marketplace (homestay-booking energy) for first-time renters.
  • Corner language: 18px card radii, 999px pills for buttons/chips; soft double-layer coral-tinted shadows.
  • Type: larger and warmer — 22px/800 headline, 16px card titles, 17px/800 prices; conversational microcopy ("That combo is fully booked").
  • States shown: scarcity card M-5 (coral "Only 1 left" tag + hot availability line); empty-state secondary with ghost pill CTA.
  • Signature: warm cream canvas, sage for positive/availability, coral strictly for action + urgency.
Direction 03

Ledger — Premium Editorial

A quiet, contract-like register: serif display type, hairline rules, a single brass accent and a lot of air position StorageHub as the premium, trustworthy option in the market. Prices are set like fine print on an invoice — large serif numerals, everything else steps back. Zero border-radius, zero shadow; hierarchy is carried entirely by rule, weight and whitespace.

Direction 03 — at a glance

  • Register: premium editorial / fine-print contract. Positions storage as a considered purchase, not a commodity.
  • Corner language: radius 0 on every surface; hairline #E7E2D9 rules replace shadows; brass 2px rule marks the variant card.
  • Type: Georgia serif for display, codes and all prices (19px numerals); 10px uppercase letterspaced sans labels at +0.14em.
  • States shown: L-3 turn-over buffer as an italic serif note with brass top rule; Unit Detail rendered as a dotted-leader contract sheet.
  • Signature: "Search →" as an underlined text action instead of a filled button; count row ruled top-and-bottom like a ledger header.
Direction 04

Control Room — Technical SaaS

A cool, data-forward register in the Stripe/Linear lineage: slate surfaces, one indigo accent, an unbending 8px grid, tabular numerals and status semantics (green/amber dots, left-edge state bars) on every card. It treats browsing units as a comparison task and gives the user instrument-panel confidence in availability and pricing.

Direction 04 — at a glance

  • Register: technical SaaS / fintech precision — browsing as an instrumented comparison task.
  • Corner language: unbending 8px radius on every surface; 1px #E2E8F0 borders + 1px shadows; 3px left status bar encodes card state (green ready / amber buffer).
  • Type: 13px base, tabular numerals for all prices/dates, mono for unit codes and filter chips; "6 units available · live" reads like a system readout.
  • States shown: L-3 buffer card (amber bar + warn availability + secondary Book button); empty state with query-string chips and ghost Clear-filters button.
  • Signature: role chip ("Customer") surfaces the adaptive shell; red 3-badge bell vs indigo action keeps alert/action channels separate.
